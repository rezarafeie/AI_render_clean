# راهنمای کامل الگوی تدوین «تاکینگ‌هد ← ریلز موشن‌دار»

> **برای Claude Code:** این سند یک خط تولید کامل و تکرارپذیر را توضیح می‌دهد. ورودی‌اش یک ویدیوی خام افقی از گوینده است (پادکست/تاکینگ‌هد، فارسی) و خروجی‌اش یک ریلز عمودی ۱۰۸۰×۱۹۲۰ با این اجزاست: جامپ‌کات، کادر هوشمند روی صورت، زیرنویس کلمه‌به‌کلمه، موشن‌گرافیک هماهنگ با حرف‌ها، افکت صوتی و موسیقی داک‌شده.
> پیاده‌سازی مرجع با **Remotion (React)** + **ffmpeg** + **Python** + **ElevenLabs** ساخته شده. سورس کامل در `edit2_source.zip` هست. هدف این سند این است که همین را در «ادیتور جی‌پی‌تی» بسازی. بخش ۱۲ نگاشت مفاهیم را برای یک ادیتور تایم‌لاین‌محور توضیح می‌دهد.
>
> نمونه‌ی اجراشده: `2.mp4` (افقی 1920×1080، 50 ثانیه) ← `edit_2_vertical.mp4` (عمودی، 40.6 ثانیه). سبک بر اساس ویدیوی مرجع `o88ewi7khq.mp4` است.

## ۰. نمای کلی

```
ویدیوی خام (افقی)
   │
   ├─① استخراج صدا ──► ② Scribe (متن + زمان هر کلمه)
   │                          │
   │                          ▼
   │                  ③ EDL جامپ‌کات (حذف مکث و «اِاِاِ») ──► cut.mp4 + voice_raw.wav + نگاشت زمان
   │                          │
   ├─④ ردیابی صورت ─────────┤
   │                          ▼
   │                  ⑤ data.json  ← beats (چیدمان + گرافیک هر بخش) + captions + sfx + face track
   │                          │
   │          ┌───────────────┴───────────────┐
   │          ▼                               ▼
   │   ⑥–⑨ رندر تصویر (Remotion)        ⑩ صدا: SFX + موسیقی (ElevenLabs) ← ⑪ میکس (ffmpeg)
   │          │                               │
   │          └──────────────► mux ◄──────────┘ ──► edit_vertical.mp4
```

**سه اصل معماری:**
1. **همه‌چیز به کلمه وصل است، نه به ثانیه.** هر beat، هر pop گرافیک و هر افکت صوتی با «اندیس کلمه» تعریف می‌شود و زمانش از روی transcript حل می‌شود. اگر کات‌ها عوض شوند، همه‌چیز خودبه‌خود جابه‌جا می‌شود.
2. **اول جامپ‌کات، بعد همه‌چیز.** بعد از کات، تایم‌لاین جدیدی ساخته می‌شود و همه‌ی زمان‌ها به این «زمان خروجی» نگاشت می‌شوند.
3. **الگو = موتور ثابت + یک فهرست beat.** برای ویدیوی بعدی فقط transcript جدید و فهرست beatها عوض می‌شود. چیدمان‌ها، زیرنویس، کتابخانه‌ی گرافیک و میکس دست نمی‌خورند.

## ۱. تحلیل سبک مرجع (چه چیزی را کپی می‌کنیم)

از روی contact sheet ویدیوی مرجع (`ffmpeg -i ref.mp4 -vf "fps=1,scale=240:-1,tile=11x4" contact.jpg`):

| عنصر | توضیح |
|---|---|
| **چیدمان دوتکه (split)** | بالا حدود ۵۳٪ پس‌زمینه‌ی روشن + گرافیک، پایین حدود ۴۷٪ گوینده با **گوشه‌های گرد بالا** |
| **تمام‌صفحه‌ی گوینده (full)** | کلوزآپ با زوم ناگهانی، زیرنویس سفید در یک‌سوم پایین |
| **صحنه‌ی تمام‌گرافیکی (graphic)** | پس‌زمینه‌ی بژ/سفید/مشکی + تیتر بزرگ سریف ایتالیک مرجانی («FIRST»، «SECOND») + کارت آیکون که pop می‌شود |
| **زیرنویس** | یک کلمه در هر لحظه. کلمه‌ی عادی = سنس‌سریف بولد، کلمه‌ی کلیدی = سریف ایتالیک درشت. کلمه‌ی پولی = سبز براق |
| **ریتم** | تقریباً هر ۱ تا ۳ ثانیه تغییر چیدمان. سر هر کات، زوم متناوب |
| **بافت** | سایه‌ی محو برگ نخل روی پس‌زمینه‌ی روشن |

معادل فارسی: سنس‌سریف = **Vazirmatn**، «سریف ایتالیک» = **Noto Naskh Arabic** برای کلمه‌های فارسی و **Playfair Display Italic** برای کلمه‌های لاتین.

## ۲. پیاده‌سازی متن با زمان هر کلمه (ElevenLabs Scribe)

```bash
ffmpeg -i input.mp4 -vn -ac 1 -ar 44100 -b:a 128k audio.mp3
curl -X POST https://api.elevenlabs.io/v1/speech-to-text \
  -H "xi-api-key: $ELEVENLABS_API_KEY" \
  -F model_id=scribe_v1 -F language_code=fas \
  -F timestamps_granularity=word -F tag_audio_events=false \
  -F file=@audio.mp3 -o scribe.json
```
خروجی: `words[]` با `{text, start, end, type}`. فقط `type == "word"` را نگه دار و به هر کلمه یک اندیس `i` بده (اندیس‌ها کلید کل سیستم‌اند).

> چرا Scribe؟ Whisper محلی روی فارسیِ محاوره کلمه‌ها را ناقص برمی‌گرداند و زمان کلمه‌به‌کلمه نمی‌دهد. Scribe هر دو را درست می‌دهد، کلمه‌های انگلیسی وسط جمله (scale، SaaS) را هم تشخیص می‌دهد، و فیلرها را به‌صورت «اِاِاِ» جدا برمی‌گرداند.

**دام:** فایل اصلی را مستقیم نفرست (حجیم است). صدای mono با 128kbps کافی است.

## ۳. جامپ‌کات (EDL) — `edl.py`

### ۳.۱ چه چیزی حذف می‌شود
- **فیلرها:** کلمه‌هایی مثل `اِاِاِ`، `اممم` و `خب`ِ بی‌معنی. در نمونه، اندیس‌های `{46, 47, 76, 93}` دستی انتخاب شدند. اتوماتیکش این است: هر کلمه‌ای که با `/^(اِ|ا|ام|اه)+$/` مچ شود، به‌اضافه‌ی «یا»/«و»ی تنهایی که درست قبل از فیلر آمده.
- **مکث‌ها:** هر فاصله‌ی بین دو کلمه که بیشتر از `MAXGAP = 0.28s` باشد کوتاه می‌شود.

### ۳.۲ الگوریتم
```python
PRE, POST, MAXGAP = 0.07, 0.10, 0.28   # حاشیه قبل/بعد هر کلمه
segs = []
for w in kept_words:                      # به ترتیب زمان
    s, e = w.start - PRE, w.end + POST
    contiguous = segs and w.i - segs[-1].last_i == 1          # کلمه‌ی حذف‌شده‌ای بینشان نیست
    if contiguous and (w.start - words[segs[-1].last_i].end) <= MAXGAP:
        segs[-1].end = e; segs[-1].last_i = w.i               # ادامه‌ی همان سگمنت
    else:
        if segs: s = max(s, segs[-1].end)                     # همپوشانی نداشته باشند
        segs.append(Seg(start=max(0, s), end=e, last_i=w.i))
# تایم‌لاین خروجی
out_t = 0
for seg in segs: seg.out = out_t; out_t += seg.end - seg.start
```
**نگاشت زمان** (`m(x)`: زمان منبع → زمان خروجی): اگر `x` داخل سگمنتی بود، `seg.out + (x - seg.start)`. همه‌ی کلمه‌ها با همین تابع به زمان خروجی می‌روند. لیست `cuts` = `seg.out` همه‌ی سگمنت‌ها به‌جز اولی (برای زوم متناوب لازم است).

### ۳.۳ ساخت ویدیوی کات‌شده
```
[0:v]trim=S:E,setpts=PTS-STARTPTS[vK];
[0:a]atrim=S:E,asetpts=PTS-STARTPTS,afade=t=in:d=0.012,afade=t=out:st=(dur-0.015):d=0.015[aK];
...[v0][a0][v1][a1]...concat=n=N:v=1:a=1[v][a]
```
- **fade صوتی ۱۲–۱۵ میلی‌ثانیه‌ای** سر و ته هر سگمنت از کلیک جلوگیری می‌کند.
- خروجی میانی: `cut.mov` (h264 crf 14، `-g 15`، صدای pcm).
- **دم ۰.۸ ثانیه‌ای:** آخر ویدیو آخرین فریم را نگه دار تا انیمیشن پایانی جا بگیرد:
  ```bash
  ffmpeg -i cut.mov -vf "tpad=stop_mode=clone:stop_duration=0.8" -an -c:v libx264 -crf 15 -g 10 cut.mp4
  ffmpeg -i cut.mov -vn -af "apad=pad_dur=0.8" -ar 48000 voice_raw.wav
  ```
  `-g 10` (keyframe زیاد) سیک کردن را در رندر سریع می‌کند.

نتیجه در نمونه: ۱۷ سگمنت، از 49.9 ثانیه به 39.8 + 0.8 = **40.6 ثانیه**.

## ۴. ردیابی صورت — `face.py`

- هر **۰.۲ ثانیه** یک فریم، کوچک‌شده به 960×540، با Haar Cascade (`haarcascade_frontalface_default.xml`). اگر صورت پیدا نشد، `profileface` و نسخه‌ی آینه‌شده‌اش امتحان می‌شود. بزرگ‌ترین صورت انتخاب می‌شود. (هر face detector بهتری مثل MediaPipe یا YuNet هم کار می‌کند.)
- خروجی: `[t, cx, cy, w]` در مختصات منبع.
- زمان‌ها با `m(t)` به زمان خروجی نگاشت می‌شوند، روی یک گرید ۰.۲ ثانیه‌ای `np.interp` می‌شوند، و با **میانگین متحرک ۹‌نقطه‌ای (حدود ۱.۸ ثانیه)** صاف می‌شوند تا کادر نلرزد.
- **تصحیح:** مرکز مستطیل Haar کمی چپ‌تر از مرکز واقعی سر است. در نمونه `+55px` اضافه شد. با یک still چک کن.
- `faceY` (ارتفاع صورت) را ثابت گرفتیم (میانه = 324)، چون گوینده‌ی نشسته عمودی جابه‌جا نمی‌شود.

## ۵. فایل داده‌ی الگو — `data.json` (خروجی `build_data.py`)

```json
{
  "total": 40.63,
  "beats":  [{"w": 1, "start": 0.52, "end": 3.02, "layout": "split", "g": "service", "zoom": 1.0}, ...],
  "caps":   [{"s": 0.54, "e": 1.06, "words": [{"t": "خدمات", "key": true, "money": false}], "i": 1}, ...],
  "sfx":    [{"t": 0.40, "f": "whoosh", "v": 0.55}, ...],
  "cuts":   [0.51, 4.2, ...],
  "face":   [1031.2, ...], "faceStep": 0.2, "faceY": 324,
  "kw":     {"4": 1.96, "10": 3.08, ...}
}
```
- `kw` = زمان خروجی کلمه‌هایی که گرافیک‌ها به آن‌ها قلاب شده‌اند. داخل گرافیک با `k(i) = kw[i] - beat.start` (زمان نسبت به شروع beat) خوانده می‌شود.

**قواعد انتخاب beat (برای ویدیوی جدید):**

- هر **اسم یا مفهوم قابل‌تصویر** (محصول، دوره، گوشی، نرم‌افزار…) → `split` با یک کارت.

- آخرین beat روی کلمه‌ی پایانی جمله `full` + پاداش بصری (سکه).

### ۶.۳ فونت‌ها
- `Vazirmatn` با وزن‌های 600/700/800/900: متن عادی و کارت‌ها
- `Noto Naskh Arabic` با وزن 700: کلمه‌های کلیدی فارسی و تیترهای بزرگ (معادل «سریف ایتالیک» مرجع)
- `Playfair Display` ایتالیک 800/900: کلمه‌های لاتین (SaaS، Scale، ×1,000)
- **قبل از رندر** با `document.fonts.load(...)` صبر کن تا فونت‌ها لود شوند.
- رقم‌ها فارسی: `fa(n)`.

### ۶.۴ بافت برگ (روی همه‌ی پس‌زمینه‌های روشن)
دو دسته برگ نخل (هر برگ = `M0,0 C60,80 70,220 0,330 C-70,220 -60,80 0,0 Z`، ۷ تا با چرخش 22 درجه، و ۵ تای کوچک‌تر). رنگ `#2d3a2a`، **opacity 0.08**، **blur 14px**، گوشه‌ی بالا-راست و بالا-چپ. با `sin(t)` خیلی آرام تاب می‌خورند (±10px، ±3 درجه).

### ۶.۵ حرکت
- easeOut: `cubic-bezier(0.16,1,0.3,1)`، easeInOut: `cubic-bezier(0.65,0,0.35,1)`
- spring پیش‌فرض: `stiffness 140, damping 11–12, mass 0.7–0.8`. پرانرژی (مهر، تیک): `damping 9, stiffness 220`
- **Pop** (پایه‌ی همه‌ی ورودها): scale از 0.3–0.5 به 1 با spring + چرخش اولیه‌ی ±6 تا ±20 درجه که به 0 برمی‌گردد + opacity در 0.12s
- **شناوری ایدل:** `sin(t*sp*2)*amp` با amp 8–12px روی کارت‌ها

## ۷. سه چیدمان (layout) و ترنزیشن

### ۷.۱ گوینده در هر چیدمان
ویدیو 1920×1080 است. با scale `S` و جابه‌جایی `tx, ty` داخل یک جعبه قرار می‌گیرد:
```
full:   box = 1080×1920,  S = (1920/1080) * zoom * alt * push,  faceTargetY = 700
split:  box = 1080×910,   S = (910/800)   * zoom * alt * push,  faceTargetY = 330
tx = clamp(boxW/2 - (faceX+55)*S,  boxW - 1920*S,  0)
ty = clamp(faceTargetY - faceY*S,  boxH - 1080*S,  0)
```
- `alt` = **زوم متناوب روی جامپ‌کات:** تعداد کات‌هایی که از شروع beat تا الان رد شده شمرده می‌شود. اگر فرد بود، 1.1 و اگر زوج بود، 1.0. پرش کات را پنهان می‌کند و انرژی می‌دهد.
- `push` = `1 + 0.025 * t` (زوم خیلی آرام داخل هر beat، حس دوربین زنده)
- clamp یعنی هیچ‌وقت لبه‌ی سیاه دیده نمی‌شود.

### ۷.۲ full
گوینده تمام‌صفحه + گرادیان تیره‌ی پایین (`transparent 55% → rgba(0,0,0,0.45) 100%`) برای خوانایی زیرنویس + overlay گرافیک (سکه یا درخشش).

### ۷.۳ split
- پس‌زمینه‌ی روشن + برگ، گرافیک در ناحیه‌ی 1080×1010 بالا
- پنجره‌ی گوینده: `top=1010`، ارتفاع 910، `border-radius: 64px 64px 0 0`، سایه‌ی `0 -20px 60px rgba(0,0,0,0.18)`. موقع ورود از 60px پایین‌تر با spring بالا می‌آید.

### ۷.۴ graphic
تمام‌صفحه پس‌زمینه (روشن / بژ / تیره) + گرافیک 1080×1920. گوینده دیده نمی‌شود.

### ۷.۵ ترنزیشن بین beatها
کات سخت + **zoom-blur ورودی** روی کل beat جدید در 0.22s: `scale 1.09→1` و `blur 14px→0`. همزمان یک افکت ووش، 0.12s قبل از شروع beat، که بین `whoosh` و `whoosh2` متناوب عوض می‌شود.

## ۸. زیرنویس کلمه‌به‌کلمه

### ۸.۱ گروه‌بندی
هر کلمه یک زیرنویس جداست، به‌جز کلمه‌های کوتاه و دستوری که به کلمه‌ی **بعدی** می‌چسبند:
```
SMALL = {که، به، رو، تو، یا، یه، این، از، هم، ما، اون، یک، توی، مثل، بهش، as، a}
```
(«به ثروت»، «تو گوشی»، «یه چیز» با هم می‌آیند.) نقطه، ویرگول و خط تیره از متن نمایشی حذف می‌شوند.
- شروع = `start(اولین کلمه) - 0.04`
- پایان = `min(end(آخرین کلمه) + 0.25, start(زیرنویس بعدی) - 0.04)`، حداقل 0.18s

### ۸.۲ جایگاه
| چیدمان | y مرکز | اندازه‌ی پایه | رنگ |
|---|---|---|---|
| full | 1500 | 96px | سفید + سایه‌ی `0 4px 18px rgba(0,0,0,.65)` |
| split | 940 (درست بالای پنجره‌ی گوینده) | 84px | INK |
| graphic | 1450–1500 | 84px | INK |
| SaaS | **مخفی** (خود گرافیک متن را نشان می‌دهد) | | |

### ۸.۳ سبک کلمه
- **عادی:** Vazirmatn 900
- **کلیدی** (لیست KEY: خدمات، ثروت، محصول، بزرگ، scale، دیجیتال، پادکست، بدون مرز، SaaS…): ‏×1.25 اندازه، Naskh 700 (یا Playfair ایتالیک برای لاتین). روی روشن = coralText، روی تیره = سفید
- **پولی** (ثروت، می‌فروشی، بفروشه): ‏×1.3، MONEY سبز + `0 0 30px rgba(59,227,122,.55)` + stroke تیره‌ی 2px روی تصویر
- **انیمیشن ورود:** scale از 0.72 به 1 با easeOutCubic در 0.12s + یک overshoot کوچک (`+0.04 * e^(-18t)`) + opacity در 0.05s. جهت `rtl`.

## ۱۰. افکت صوتی و موسیقی (ElevenLabs)

### ۱۰.۱ افکت‌ها — `POST /v1/sound-generation`
بدنه: `{text, duration_seconds, prompt_influence: 0.6}`
| فایل | prompt | مدت |
|---|---|---|
| whoosh | fast clean cinematic whoosh transition, short airy swish | 0.8 |
| whoosh2 | quick low swoosh pass by, punchy video edit transition | 0.7 |
| pop | soft bubbly UI pop, satisfying click for a card appearing | 0.5 |
| coins | handful of gold coins jingling and dropping, bright cash sound | 1.5 |
| stamp | heavy rubber stamp thud on paper, deep impact | 0.6 |
| riser | short tension riser building up into a hit, modern tech trailer | 2.0 |
| impact | deep cinematic boom impact with sub bass tail | 1.5 |
| typing | fast mechanical keyboard typing burst | 1.2 |
| ding | bright positive success notification ding | 0.8 |
| swipe | short digital UI swipe swoosh upward, futuristic | 0.6 |
| sparkle | magical shimmering sparkle glitter twinkle | 1.0 |

این‌ها **یک بار** ساخته می‌شوند و برای همه‌ی ویدیوهای بعدی قابل استفاده‌اند (کتابخانه‌ی ثابت الگو).

### ۱۰.۲ موسیقی — `POST /v1/music`
```json
{"prompt": "Upbeat modern minimal tech lo-fi hip hop instrumental for a business podcast short video, punchy kick and snare, warm electric piano chords, subtle plucks, confident and motivating, steady 100 bpm groove, no vocals, clean mix suitable as background under speech",
 "music_length_ms": 52000, "force_instrumental": true}
```
خروجی `mp3_44100_128` (فرمت 192 پلن Creator می‌خواهد).

### ۱۰.۳ قواعد جای‌گذاری افکت
- **ووش** سر هر beat (0.12s قبل)، با volume 0.55 و متناوب whoosh/whoosh2
- **pop** سر ورود هر کارت (0.05s قبل)، با volume 0.7
- **swipe** برای پله‌های نمودار و ورود کلمه‌های لاتین
- **riser → impact** برای بزرگ‌ترین reveal ویدیو (SaaS): riser از ۱.۵ ثانیه قبل
- **coins** برای کلمه‌های پولی، **ding** برای تیک یا موفقیت، **stamp** برای «نه/ممنوع»، **sparkle** برای «جدید» و برند
- volume نهایی هر افکت = `v × 0.8`

## ۱۱. میکس صدا — `mix.py` (ffmpeg)

```
voice: highpass=f=70, acompressor=threshold=-20dB:ratio=3:attack=5:release=120:makeup=4dB  → [voice][sc]
music: volume=0.18, afade in 0.6s, afade out 1.6s
       sidechaincompress(music, sc) threshold=0.03 ratio=6 attack=20 release=350   ← داکینگ زیر صدا
sfx:   هر افکت با adelay=ms|ms و volume مخصوص خودش → amix(normalize=0)
final: amix(voice, music, sfx, normalize=0) → alimiter=0.95 → loudnorm I=-14 TP=-1.2 LRA=9
```
سطح‌های هدف: گفتار حدود 18- dB RMS، موسیقی تنها حدود 27- dB (پشت صدا حدود 33-). یعنی موسیقی ~۹dB زیر صداست و موقع صحبت تا ~۱۵dB پایین می‌رود. loudnorm روی ‎-14 LUFS برای اینستاگرام.

## ۱۲. رندر، mux و QA

```bash
npx remotion render src/index.ts Edit out/video.mp4 --muted --codec h264 --crf 17 --concurrency 2
ffmpeg -i out/video.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart edit_vertical.mp4
```
**QA با still قبل از رندر کامل:** از وسط یا انتهای هر beat یک still با نصف رزولوشن بگیر و در یک contact sheet شش‌تایی ببین. مشکلاتی که در نمونه پیدا و رفع شد:
- صورت در کادر کمی به راست افتاده بود ← `+55px` به faceX
- زیرنویس full روی میکروفون افتاده بود ← y از 1330 به 1500
- در صحنه‌ی SaaS کلمه‌ی «Service» دوبار دیده می‌شد (زیرنویس + گرافیک) ← زیرنویس در این beat مخفی شد
- شمارنده‌ی ضریب روی برچسب «Scale Level» افتاده بود ← به گوشه‌ی بالا-چپ منتقل شد
- coralText روی پس‌زمینه‌ی روشن کم‌رنگ دیده می‌شد ← گرادیان تیره‌تر شد
- سکه‌ها روی زیرنویس پولی می‌افتادند ← مبدأ پرتاب پایین‌تر رفت و متن پولی stroke تیره گرفت
