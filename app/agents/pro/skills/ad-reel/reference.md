## ۰. نمای کلی

```
لینک محصول
   │
   ├─① رندر صفحه در مرورگر ← عنوان، قیمت، ویژگی‌ها، تضمین‌ها، لیست عکس‌ها
   │
   ├─② متن تبلیغ (۱۲ جمله، فرمول بخش ۲) ← lines.json
   │        │
   │        ▼
   │   ③ ElevenLabs TTS جمله‌به‌جمله + timestamps ← ④ QA با Scribe ← بازسازی جمله‌های خراب
   │        │
   │        ▼
   │   ⑤ پردازش صدا (حذف سکوت + atempo 1.15 + نگاشت alignment) ← voice_al.json
   │        │
   │        ▼
   │   ⑥ تایم‌لاین (data.json): شروع هر صحنه + زمان هر کلمه
   │
   ├─⑦ دانلود عکس‌ها ← cutout (حذف پس‌زمینه‌ی سفید و نوشته‌های چاپی) ← PNG شفاف
   │
   ├─⑧ ۱۲ صحنه‌ی موشن (Remotion) + زیرنویس کارائوکه + نوار پیشرفت ← video.mp4 (بی‌صدا)
   │
   └─⑨ SFX + موسیقی (ElevenLabs) ← ⑩ میکس (ffmpeg) ← mux ← reel.mp4
```

**اصول:**
1. **صدا اول، تصویر بعد.** طول هر صحنه = طول جمله‌ی نریشن. هر انیمیشن به یک **کلمه** قلاب می‌شود (`c('کلمه')`).
2. **عکس واقعی محصول، نه تصویر ساختگی.** همه‌ی ابزارها و کیف از عکس‌های خود صفحه‌ی فروش بریده شده‌اند. موشن‌گرافیک فقط دورشان ساخته می‌شود.
3. **ادعای صادقانه.** هر ادعای متن باید از صفحه‌ی محصول بیاید. کمبود موجودی، تخفیف یا عدد ساختگی ممنوع است. هر جا صفحه ضدونقیض بود، کلی‌تر بگو (بخش ۲.۳).
4. **الگو = موتور ثابت + انتخاب «نوع صحنه» برای هر جمله.** برای محصول بعدی فقط متن، عکس‌ها و نگاشت جمله به نوع صحنه عوض می‌شود.

## ۱. استخراج اطلاعات محصول

صفحه‌های فروشگاه (Lovable / SPA) با JavaScript رندر می‌شوند و fetch ساده فقط پوسته‌ی خالی برمی‌گرداند. پس **مرورگر واقعی** لازم است:
1. صفحه را باز کن، حدود ۴ ثانیه صبر کن، بعد `innerText` بگیر: عنوان، قیمت، Key features، تضمین‌ها (Secure Checkout، 30-Day Money Back، Fast Delivery، 24/7 Support)، Shipping & guarantees و نام فروشنده.
2. لیست عکس‌ها:
   ```js
   [...new Set([...document.querySelectorAll('img')].map(i => i.currentSrc || i.src))]
   ```
   عکس‌های گالری روی `cf.cjdropshipping.com` هستند. پارامتر `?x-oss-process=...` را حذف کن تا نسخه‌ی اصلی (2001×2001) دانلود شود.
3. یک contact sheet از عکس‌ها بساز (`ffmpeg -pattern_type glob -i 'p*.jpg' -vf "scale=360:360,tile=4x4"`) و ببین کدام عکس چه چیزی را نشان می‌دهد: کیت باز، کیف بسته، تک‌ابزارها، لوازم جانبی، جدول قطعات.

> **نکته‌ی شبکه:** دامنه‌ی عکس‌ها (`cf.cjdropshipping.com`) و `api.elevenlabs.io` باید در allowlist باشند.

### ۲.۲ قواعد نوشتن برای TTS فارسی (ElevenLabs v3)
- **محاوره‌ای بنویس** («می‌شه»، «میری»، «کارای»). رسمی بنویسی، رسمی می‌خواند.
- **کسره‌ی اضافه** جایی که نباید جا بیفتد: «آچارِ دستی»، «کیتِ ابزارِ بادیِ…».
- **نیم‌فاصله** در «می‌کنه»، «جغجغه‌ی»، «به‌علاوه‌ی».
- **عددها با حروف** («هفتاد و یک»، «صد و سی و سه دلار و نود و نه سنت»). روی صفحه با رقم فارسی نشان داده می‌شوند.
- **تگ احساس v3** اول جمله: `[excited]` برای هوک، معرفی، قیمت و CTA. تگ `[shouting]` روی «دیگه بسه» باعث شد Scribe «یه بسه» بشنود. با `[excited] دیگه، بسه!` درست شد. تگ‌ها خوانده نمی‌شوند و در alignment هم می‌آیند، پس موقع ساختن کلمه‌ها حذفشان کن.
- **ویرگول** = مکث کوتاه، `...` = مکث دراماتیک (بعد از پردازش 0.32 ثانیه نگه داشته می‌شود).

### ۲.۳ قواعد صداقت در ادعاها
- فقط چیزی که صفحه می‌گوید. «تو چند ثانیه» برای بکس بادی توصیف معمول عملکرد ابزار است، نه عدد ساختگی.
- **کمبود موجودی، تخفیف، قیمت قبلی یا تعداد خریدار** فقط اگر صفحه داشت.
- تضاد در صفحه (30 روز در برابر 7 روز) ← **عدد نگو**، فقط «ضمانت بازگشت پول».

## ۳. تولید صدا (ElevenLabs)

```
POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/with-timestamps?output_format=mp3_44100_128
{"text": "...", "model_id": "eleven_v3", "language_code": "fa",
 "voice_settings": {"stability": 0.5, "similarity_boost": 0.8}}
```
- `voice_id = wEMHmIPIdyXK6OkgkB03` («صدای من»، کلون صدای رضا)
- هر جمله جدا ← `voice/NN.mp3` + `voice/NN.json` (alignment: `characters`، `character_start_times_seconds`)
- فرمت 192kbps پلن Creator می‌خواهد و روی پلن پایین‌تر 403 می‌دهد.
- فایل را **بعد از** پاسخ موفق بنویس، تا خطا فایل صفربایتی باقی نگذارد.

### ۳.۱ کنترل کیفیت با Scribe (اجباری)
همه‌ی کلیپ‌های پردازش‌شده را پشت هم بچسبان و به `POST /v1/speech-to-text` (‏`model_id=scribe_v1`، `language_code=fas`) بده. متن برگشتی را با متن اصلی مقایسه کن. هر جمله‌ای که کلمه‌ی کلیدی‌اش اشتباه شنیده شد، فقط **همان جمله** را دوباره بساز. اختلاف‌های کوچک تلفظی («جقجقه»، «نمیره») قابل‌قبول‌اند.

## ۴. پردازش صدا — `proc_voice.py`

1. تبدیل به 48kHz mono
2. `silencedetect=n=-40dB:d=0.22`
   - سکوت **اول کلیپ** حذف شود (تا 0.05 ثانیه قبل از صدا)
   - سکوت **آخر** حذف شود (0.08 ثانیه نگه دار)
   - سکوت **وسط** به `KEEP = 0.13s` کوتاه شود. برای جمله‌های دراماتیک (01، 11) به 0.32
3. `atempo=1.15` (ریتم تبلیغ)
4. **نگاشت alignment:** هر زمان x ← (مجموع طول قطعه‌های نگه‌داشته‌شده تا x) / 1.15
5. خروجی: `proc/NN.wav` (استریو) + `voice_al.json` (`{chars, starts, dur, text}`)

نتیجه: از ۵۳ ثانیه‌ی خام به **۴۲.۸ ثانیه**.

## ۵. تایم‌لاین — `build.py` ← `data.json`

```python
LEAD, GAP, TAIL = 0.15, 0.12, 1.6     # شروع، فاصله‌ی بین جمله‌ها، دم پایانی برای CTA
for each line:
    words = tokens of chars (split on spaces), skip [tags], strip punctuation .،,!؟?:…«»
    word.s = starts[char index of token]; word.e = next word.s (or clip dur)
    scene = {id, start: t, dur, words}; t += dur + GAP
scene.end = next.start (last: total = t - GAP + TAIL)
```
| صحنه | start | dur | | صحنه | start | dur |
|---|---|---|---|---|---|---|
| 01 هوک | 0.15 | 3.45 | | 07 فرز | 19.31 | 3.70 |
| 02 درد | 3.72 | 4.87 | | 08 چکش | 23.14 | 1.97 |
| 03 بسه | 8.71 | 1.23 | | 09 لوازم | 25.23 | 6.25 |
| 04 معرفی | 10.06 | 2.38 | | 10 اعتماد | 31.60 | 5.03 |
| 05 بکس | 12.56 | 3.49 | | 11 قیمت | 36.75 | 4.65 |
| 06 جغجغه | 16.17 | 3.03 | | 12 CTA | 41.51 | 2.74 (+1.6) |

**تابع cue در هر صحنه:** `c(word, occ=0)` = زمان شروع اولین کلمه‌ای که برابر `word` است یا با آن شروع می‌شود (برای «تعمیرگاهِ» یا «اتصالاتِ» با کسره)، نسبت به شروع صحنه.

## ۶. آماده‌سازی عکس‌ها (cutout) — `cutout.py`

```python
white = (min(R,G,B) > 232) & (max - min < 18)          # سفید و بی‌رنگ
floodFill از ۸ نقطه‌ی لبه روی white  → background
fg = NOT background → morphology open 3×3
connected components: فقط اجزای بزرگ‌تر از minfrac × مساحت      # نوشته‌های چاپی حذف می‌شوند
alpha = GaussianBlur(mask, σ=1.2) × 1.15                 # لبه‌ی نرم
crop به bbox + 10px، حداکثر ضلع 1200 → PNG
```
- **حذف برچسب‌های چاپی** (IMPACT WRENCH و…): یا با crop عمودی (`y1=0.80` یعنی ۲۰٪ پایین بریده شود)، یا با فیلتر اندازه‌ی component (‏`minfrac=0.01` برای چکش که نوشته کنارش است).
- **جدا کردن ابزار از لوازمش:** همان عکس دو بار با بازه‌ی عمودی متفاوت بریده می‌شود (`grinder_only` بازه‌ی 0–0.44 و `stones` بازه‌ی 0.44–0.72، `ratchet_only` و `bits`).
- عکس‌های «عکاسی‌شده» (کلوزآپ لوازم با ذره‌بین) cutout نمی‌شوند و داخل کارت با border سفید می‌روند.

### ۷.۲ لایه‌های پس‌زمینه (ثابت، زیر همه‌ی صحنه‌ها)
1. گرادیان شعاعی تیره
2. **۵ نوار نور مورب** (24 درجه) که با سرعت 140px/s حرکت می‌کنند: قرمز با opacity 0.07 و سفید با 0.03
3. **گرین فیلم:** `feTurbulence fractalNoise baseFrequency=0.85`، با seed که هر فریم عوض می‌شود (`f % 8`)، opacity 0.09، blend overlay
4. ویگنت `inset 0 0 300px rgba(0,0,0,.85)`
5. **نوار پیشرفت** بالای کادر: ارتفاع 10px، قرمز با glow، از راست پر می‌شود (برای نگه‌داشتن بیننده)

کات سخت + ورود: **scale 1.14→1 و blur 18→0 در 0.2s** روی کل صحنه + ووش 0.1 ثانیه قبل. صحنه‌های ضربه‌ای (03، 04) فلش سفید هم دارند.

## ۸. استوری‌بورد صحنه‌به‌صحنه

> «@کلمه» = `c('کلمه')`. مختصات در بوم 1080×1920. **ناحیه‌ی 1560 تا 1760 مال زیرنویس است**، چیزی آنجا نگذار.

## ۹. زیرنویس کارائوکه

- **گروه‌بندی:** حداکثر ۳ کلمه در هر گروه، یا گروه جدید وقتی فاصله‌ی دو کلمه بیشتر از 0.3s است. شروع گروه = اولین کلمه − 0.03، پایان = آخرین کلمه + 0.15 (تا شروع گروه بعد).
- **جایگاه:** y=1665، وسط‌چین، `rtl`، padding افقی 60.
- **سبک:** Vazirmatn 900، سفید 76px، `WebkitTextStroke: 10px #000` + `paint-order: stroke fill` + سایه.
- **کلمه‌ی در حال گفتن:** زرد `#FFD400`، 84px، بالا آمده 4px و 2- درجه چرخیده.
- **ورود گروه:** scale 0.8→1 در 0.1s.
- **مخفی** در صحنه‌های 03 و 11، چون متن بزرگ روی صفحه همان را می‌گوید.

## ۱۱. میکس — `mix.py`

```
voice:  ۱۲ کلیپ با adelay ← amix ← highpass 60 ← acompressor(-18dB, 3:1, makeup 3dB)
        ← apad=whole_dur=T   ← مهم: بدون این، sidechain موزیک را سر آخرین کلمه قطع می‌کند
        ← asplit [voice][sc]
music:  volume 0.24, fade in 0.3s, fade out 1.8s ← sidechaincompress(sc, threshold 0.04, ratio 5, attack 15, release 300)
sfx:    هر cue با adelay و volume = v × 0.75 ← amix(normalize=0)
final:  amix(voice, music, sfx) ← atrim T ← alimiter 0.95 ← loudnorm I=-13 TP=-1 LRA=8
```
- ضربه‌های دراماتیک (shatter، boom) را **کم‌صدا** بگذار (0.3، 0.28)، چون فریاد نریشن خودش بلند است. در نمونه، اول ۱ ثانیه‌ی آن لحظه تا 6.8- dB RMS رفته بود.
- هدف: گفتار حدود 16- تا 18- dB RMS. موزیک تنها حدود 24- قبل از داکینگ.
