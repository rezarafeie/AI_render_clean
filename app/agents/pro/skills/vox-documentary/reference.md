# موتور ساخت ویدیوی «Vox Style» برای ادیتور جی‌پی‌تی

### پرامپت + مشخصات فنی کامل برای Claude Code

## ۰. پرامپت اصلی (این بخش را عیناً به Claude Code بده)

```
تو داری یک «موتور Vox Style» به ادیتور جی‌پی‌تی اضافه می‌کنی.
ورودی کاربر: یک موضوع یا ایده (مثلاً «یه ویدیو درباره‌ی دراپ‌شیپینگ»)، یا یک متن آماده.
خروجی: یک ویدیوی مستند-توضیحی عمودی 1080×1920 با 30fps، به سبک Vox / کلاژ کاغذی:
  نریشن فارسی، تصاویر سیاه‌وسفید بریده با حاشیه‌ی کاغذی، پس‌زمینه‌ی کاغذ،
  علامت‌های ماژیکی دست‌کش، تایپ ماشین‌تحریری، نقشه، نمودار، مهر و هایلایت،
  همه هماهنگ با کلمه‌های نریشن.

موتور ۷ مرحله دارد و هر مرحله خروجی مشخص و قابل‌بازبینی دارد:
  1) Story     موضوع → تحقیق → انتخاب داستان → متن ۱۲ تا ۱۶ جمله‌ای با منبع       → story.json
  2) Voice     متن → TTS جمله‌به‌جمله با timestamp → QA با STT → پردازش             → voice_al.json + proc/*.wav
  3) Timeline  طول جمله‌ها و زمان کلمه‌ها → زمان شروع صحنه‌ها                       → timeline.json
  4) Storyboard هر جمله → یک «نوع صحنه» از کتابخانه + المان‌ها + قلاب کلمه‌ای       → storyboard.json
  5) Assets    لیست تصاویر لازم → تولید شیت تصویر (AI) → برش → حاشیه‌ی کاغذی          → img/*.png
  6) Render    storyboard + timeline + assets → Remotion (پریمیتیوهای بخش ۶)          → video.mp4 (بی‌صدا)
  7) Sound     موسیقی مستند + افکت‌های کاغذی روی رویدادها + داکینگ + loudnorm         → final.mp4

قواعد غیرقابل‌مذاکره:
  - هر عدد، تاریخ و نقل‌قول باید منبع داشته باشد. اگر منبع‌ها ضدونقیض بودند، عدد محافظه‌کارانه یا «حدود» بگو و در story.json یادداشت کن.
  - از آدم‌های واقعی عکس نگذار و تصویر شبیهشان هم نساز. اسمشان را روی برچسب بنویس و از تصویر آدم بی‌نام یا نقل‌قول کارتی استفاده کن.
  - روی تصاویر لوگو یا برند نباشد (در پرامپت تولید تصویر «no text, no logos» بنویس و خروجی را چک کن).
  - هر انیمیشن به یک «کلمه» از نریشن قلاب می‌شود (cue)، نه به یک ثانیه‌ی ثابت.
  - قبل از رندر کامل، از هر صحنه یک still بگیر و چک‌لیست QA بخش ۹ را رد کن.
مشخصات دقیق هر مرحله در ادامه‌ی همین سند است. پیاده‌سازی مرجع در vox_engine_source.zip است.
```

## ۱. DNA سبک Vox (از تحلیل ۹ ویدیوی مرجع)

| محور | قاعده |
|---|---|
| **سطح** | کاغذ: مچاله‌ی کرم (`#EEE5D9`)، کاغذ شطرنجی، یا کاغذ رنگی (خردلی، قرمز). کاغذ تیره برای نقل‌قول |
| **تصویر** | عکس **سیاه‌وسفید، پرکنتراست، با دانه‌ی چاپ** (حس روزنامه‌ی قدیمی). دو شکل دارد: **برش** (cutout با حاشیه‌ی سفید ۱۴px مثل استیکر) یا **عکس چاپی** (قاب سفید + نوار چسب) |
| **رنگ** | فقط ۲ تا ۳ رنگ تأکیدی، تخت و بدون گرادیان: قرمز `#D9432F` · خردلی `#F2B33D` · فیروزه‌ای `#2A9D8F`. جوهر `#1C1B19` |
| **شکل** | دایره و نیم‌دایره‌ی رنگی بزرگ **پشت** تصویرها (blend multiply)، نوار کاغذ پاره‌شده |
| **دست** | ماژیک قرمز: دور دایره، زیرخط، ضربدر، تیک، فلش منحنی، قلب. همه **می‌لرزند** (هر ۳ فریم کمی جابه‌جا) |
| **تایپ** | تیتر فارسی سنگین (Doran ExtraBold)؛ اعداد و سال‌ها با **فونت ماشین‌تحریر** (Special Elite) که حرف‌به‌حرف تایپ می‌شود؛ کلمه‌ی انگلیسی تیتر با **Anton** (فشرده و بولد)؛ برچسب‌های کاغذی کج |
| **تأکید** | ماژیک هایلایت خردلی پشت کلمه، مهر لاستیکی کج، شمارنده‌ی عدد |
| **داده** | نقشه با کشور/ایالت رنگی و سنجاق، نمودار خطی که رسم می‌شود، نمودار دایره‌ای با تکه‌ای که بیرون کشیده می‌شود |
| **حرکت** | ورود با spring یا لغزش از لبه؛ دوربین هر صحنه آرام نزدیک می‌شود (3.5٪)؛ لرزش ریز هر ۳ فریم (حس استاپ‌موشن) |
| **ترنزیشن** | صفحه‌ی جدید **مثل برگه‌ی کاغذ** از چپ یا راست روی قبلی کشیده می‌شود (با سایه). برای لحظه‌های بزرگ، **باز شدن دایره‌ای** |
| **صدا** | موسیقی مستند کنجکاوانه (پیتزیکاتو، ماریمبا، تیک‌تاک) + افکت‌های کاغذی برای هر حرکت |

## ۲. مرحله‌ی Story — انتخاب و نوشتن داستان

### ۲.۱ انتخاب زاویه
موضوع کلی (مثلاً «دراپ‌شیپینگ») را به **یک داستان مشخص** تبدیل کن. بین این قالب‌ها جذاب‌ترین را انتخاب کن (یا قالب تازه بساز):

| قالب | مثال | چرا جذاب است |
|---|---|---|
| **شروع کوچک ← نتیجه‌ی بزرگ** | زاپوس: عکس کفش ← ۱.۲ میلیارد دلار | تضاد عددی = هوک طبیعی |
| **پیچ غیرمنتظره** | زاپوس دراپ‌شیپینگ را کنار گذاشت | درس واقعی، ضد کلیشه |
| **منشأ یک چیز آشنا** | «اولین فروش آنلاین تاریخ» | کنجکاوی |
| **سقوط** | برندی که با دراپ‌شیپینگ اوج گرفت و زمین خورد | هشدار + درس |
| **مقایسه‌ی دو مسیر** | دو نفر، یک محصول، دو نتیجه | ساختار روشن |

**معیار انتخاب:** (۱) با منبع معتبر قابل‌تأیید باشد، (۲) یک عدد یا تضاد بزرگ برای هوک داشته باشد، (۳) یک درس کاربردی برای مخاطب داشته باشد، (۴) قابل‌تصویر باشد (اشیا، مکان‌ها، نقشه، نمودار).

### ۲.۲ تحقیق
- دست‌کم ۳ منبع جدا (رسانه‌ی معتبر، مصاحبه‌ی مستقیم، ویکی‌پدیا برای خط زمانی).
- از هر منبع **عدد، تاریخ و نقل‌قول مستقیم** دربیاور و تضادها را ثبت کن.
- خروجی `story.json`:
```json
{
  "angle": "شروع کوچک ← نتیجه‌ی بزرگ + پیچ",
  "facts": [
    {"claim": "Amazon acquired Zappos (2009), ~$1.2B at close", "sources": ["wiki", "fortune"],
     "conflict": "announcement figures $807M/$928M"},
    {"claim": "2003: ~25% of revenue from drop ship, ended it", "sources": ["bloomberg 2010", "marketingsherpa 2007"]}
  ],
  "lines": [["01", "آمازون، برای یه سایتِ فروشِ کفش، حدودِ یک میلیارد و دویست میلیون دلار پول داد."], "..."],
  "sources_footer": "Sources: Fortune (2012) · Bloomberg (2010) · MarketingSherpa (2007) · Wikipedia"
}
```

### ۲.۳ ساختار متن (۱۲ تا ۱۶ جمله، ۷۰ تا ۱۰۰ ثانیه)
| بخش | جمله‌ها | کار |
|---|---|---|
| **هوک** | ۱ تا ۲ | عدد یا تضاد بزرگ از **انتهای** داستان + «ولی…» |
| **زمینه** | ۱ تا ۲ | سال، مکان، شخص («سالِ ۱۹۹۹، سان‌فرانسیسکو…») |
| **ایده / مسئله** | ۲ تا ۳ | چه کار عجیبی کرد. نقل‌قول یا بازسازی پیشنهاد |
| **نام‌گذاری** | ۱ | «امروز اسم این مدل رو گذاشتیم: …» (ربط به موضوع مخاطب) |
| **رشد** | ۱ تا ۲ | اولین عددها |
| **پیچ** | ۲ تا ۳ | تصمیم غیرمنتظره + دلیلش + نقل‌قول |
| **اوج** | ۲ | بزرگ‌ترین عدد و پایان داستان |
| **درس** | ۱ | یک جمله‌ی قابل‌نقل که مخاطب یادش بماند |

**قواعد نوشتن برای TTS:** محاوره‌ای؛ نیم‌فاصله؛ کسره‌ی اضافه («سایتِ فروشِ کفش»)؛ **عددها و سال‌ها با حروف** («هزار و نهصد و نود و نه»)؛ `...` برای مکث دراماتیک؛ اسم خاص خارجی با تلفظ فارسی («نیک سوینمِرن»، «تونی شیه»).

## ۳. مرحله‌ی Voice

```
POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/with-timestamps?output_format=mp3_44100_128
{"text": line, "model_id": "eleven_v3", "language_code": "fa",
 "voice_settings": {"stability": 0.5, "similarity_boost": 0.8}}
→ voice/NN.mp3 + voice/NN.json (alignment)
```
- لحن مستند آرام است، پس **تگ احساس نزن** (برخلاف تبلیغ).
- فایل را فقط **بعد** از پاسخ موفق بنویس. اگر شبکه قطع شد، دوباره اجرا کن (جمله‌های ساخته‌شده skip می‌شوند).
- **QA اجباری:** همه را بچسبان ← Scribe (`scribe_v1`, `fas`) ← با متن مقایسه کن ← فقط جمله‌های خراب را دوباره بساز.
- **پردازش** (`proc_voice.py`):
  - سکوت‌های بیشتر از 0.16s به 0.12s کوتاه شوند (جمله‌های دراماتیک 0.34s نگه دارند)
  - `atempo=1.2`
  - زمان‌های alignment با همین نگاشت تبدیل شوند
- **هدف طول:** ۷۰ تا ۱۰۰ ثانیه. اگر بیشتر شد، اول متن را کوتاه کن، بعد tempo را تا 1.25 ببر.

## ۴. مرحله‌ی Timeline
```python
LEAD, GAP, TAIL = 0.35, 0.22, 2.2      # مستند: نفس‌کشیدن بین جمله‌ها بیشتر از تبلیغ
scene[i].start = LEAD + sum(dur[:i]) + GAP*i
scene[i].end   = scene[i+1].start  (آخری: total)
```

## ۶. مرحله‌ی Assets — تولید و برش تصاویر

### ۶.۱ فهرست تصاویر از روی storyboard
برای هر صحنه: یک تصویر «قهرمان» + المان‌ها. سه دسته:
- **اشیا** (کفش، کامپیوتر، دوربین، جعبه، پول…) ← برش با حاشیه‌ی کاغذی
- **مکان‌ها** (مغازه، انبار، قفسه…) ← عکس چاپی با قاب و چسب
- **آدم‌های بی‌نام** (از پشت، صورت در سایه، جمعیت، کارگر) ← برش

### ۶.۲ تولید به‌صورت «شیت» (صرفه‌جویی ۶ برابری)
در هر درخواست **۶ شیء در یک گرید ۳×۲** بخواه:
```
Sheet of 6 separate vintage black-and-white halftone newspaper photo cutouts on a pure white
background, evenly spaced in a 3x2 grid with generous white space between them, no text, no logos:
1) ..., 2) ..., 3) ..., 4) ..., 5) ..., 6) ...
High contrast, grainy print texture, documentary collage style.
```
- برای آدم‌ها اضافه کن: `anonymous people, faces not detailed, seen from behind or face in shadow`.
- برای مکان‌ها: `absolutely no text, no signs`.
- مدل: `gpt-image-2.5-sunburst` (هر شیت ۴ نسخه، حدود ۷۶۰ کردیت). از بین ۴ نسخه، **برای هر خانه بهترین** را انتخاب کن (اجباری نیست همه از یک شیت باشند).
- **چک برند:** خروجی را ببین و هر خانه‌ای که لوگوی واقعی دارد، کنار بگذار (در نمونه، لوگوی نایکی روی کفش یک نسخه بود).

### ۶.۳ برش (`cut.py`)
```
cell = sheet[r*h/2:(r+1)*h/2, c*w/3:(c+1)*w/3]
white = min(R,G,B) > 226  →  floodFill از ۸ نقطه‌ی لبه  →  fg = not background
close 5×5, open 3×3  →  حذف اجزای کوچک‌تر از 0.2٪ مساحت  →  پر کردن سوراخ‌ها (contour fill)
grayscale + contrast 1.12  →  upscale ×2.5 (Lanczos) + unsharp
alpha = mask نرم  →  حاشیه‌ی کاغذی: dilate(mask, 14px) با رنگ سفید زیر تصویر
crop به bbox  →  PNG
```
عکس‌های مکان: crop به محتوای غیرسفید، grayscale، upscale و JPG.
**QA:** همه را روی پس‌زمینه‌ی رنگی کنار هم بچین (contact sheet) و لبه‌ها را چک کن.

### ۶.۴ بافت کاغذ (`make_tex.py`، یک بار برای همیشه)
```
height = Σ noise(scale) با scaleهای 240، 120، 48 و 16 − |noise| برای چین‌ها
shade  = −0.6·∂x − 0.8·∂y  (نور از بالا-چپ)
color  = #EEE5D9 × (1 + 0.06·shade) + فیبرها (0.4٪ پیکسل‌ها 10٪ تیره‌تر) + گرین ±3.5 + ویگنت 18٪
grid   = همان + خطوط هر 54px با 7٪ تیره‌تر
```
کاغذ رنگی و تیره = همین بافت + لایه‌ی رنگ با `mix-blend-mode: multiply`.

### ۶.۵ نقشه
GeoJSON ایالت‌های آمریکا (یا کشورهای جهان) ← تصویر `x = (lon+125)·cos(38°)·k`، `y = (50−lat)·k` ← `usmap.json` شامل `{paths, pts, w, h}`. شهرها و نقاط مهم از قبل تصویر شوند (`pts.sf`، `pts.ky`). برای نقشه‌ی جهان از Natural Earth با همین روش استفاده کن.
