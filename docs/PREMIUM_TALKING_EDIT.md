# تدوین صحبتی پریمیوم تمام‌قاب (`creative/claude_premium`)

موتور مرجع v3 کاربر («بدون مرز – قسمت ۱»)، به‌صورت موتور: هر ویدیوی گوینده یک کادر عمودی کامل ۱۰۸۰×۱۹۲۰ می‌شود (نه دوتکه).
روش و دلیل هر تصمیم در `docs/PREMIUM_EDIT_PLAYBOOK.md` است؛ اینجا فقط نقشهٔ پیاده‌سازی.

## چه زمانی اجرا می‌شود
فقط وقتی خواسته شود: ابزار `analyze_talking_reel` با `variant="premium"`، یا درخواست حاوی «تمام‌قاب / پریمیوم / premium / full-frame».
مقدار در `talking_reel.json` به‌صورت `variant: "premium"` می‌ماند و رندر دوباره هم همین موتور را می‌گیرد (`app/talking_reel.py:_run`).
کلید خاموش‌کردن: `PREMIUM_TALKING=0`. موتور دیگری عوض نشده است.

## خط تولید (`creative/claude_premium/__init__.py:make`)
1. **متن** (Scribe) و **جامپ‌کات** (همان `claude_talking.edl`).
2. **`graded.mp4`**: برش + تون‌مپ HDR (اگر HLG/PQ) + اصلاح رنگ (`warm-lux` / `cine` / `natural`) + دم ۱ ثانیه‌ای.
3. **ردیابی صورت** (YuNet) برای دوربین مجازی.
4. **نقشهٔ لحظه‌ها** (Opus، `PLAN_GUIDE`): کارت، نوشتهٔ پشت سوژه (`word` / `latin` / `stepped`)، فهرست، پایان، زوم‌ها، کلمه‌های کلیدی، پالت.
5. **برنامه‌ریزی** (`schedule`): قانون تنفس، یک ناحیه یک المان، سقف پنجره‌های جداسازی (۵ پنجره، ۱۴ ثانیه)، فقط یک اوج.
6. **جداسازی سوژه** (`segment.py`): `u2net_human_seg` با onnxruntime، فقط پنجره‌های لازم، خروجی WebM آلفا. اگر مدل/ابزار نبود یا یک پنجره شکست، همان نوشته به کارت شیشه‌ای تبدیل می‌شود.
7. **Remotion** (`kit/src/Premium.tsx`): همه‌چیز از `data.json` رسم می‌شود؛ کدی برای هر ویدیو نوشته نمی‌شود، پس ساخت با کد خراب شکست نمی‌خورد.
8. عکس‌های بررسی + بازبینی عینی، رندر (RunPod یا محلی، همان `render_video`)، میکس (کمپرسور، موسیقی با داکینگ، افکت گره‌خورده به هر لحظه، ‑۱۴ LUFS).

مدل جداسازی در `assets/models/u2net_human_seg.onnx` نگه داشته می‌شود (روی سرور پوشهٔ ماندگار `/opt/ai-render/assets/models`)؛ اگر نبود یک بار دانلود می‌شود.
